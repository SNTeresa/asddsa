## Инструкция для продолжения работы
* **Что сделано:** Исправлены баги с ложным дублированием Пушкина и потерей данных при удалении книг
* **Что осталось сделать:** Реализовать дополнительную функцию поиска книг по автору (`find_by_author`)
* **Важные файлы:** `storage.py` (бизнес-логика), `main.py` (точка входа), `data/books.json` (база данных)
* **Как запустить и проверить:** Выполнить команду `python main.py`, убедиться, что новые логи пишутся в файл `logs/operations.log`, а файл `books.json` обновляется автоматически
