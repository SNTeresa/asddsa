# Отчёт о багах

## Баг 1: ложное срабатывание проверки дубликатов
- **Шаги воспроизведения:** добавить "Капитанская дочка" (Пушкин).
- **Ожидаемое поведение:** книга добавляется в список.
- **Фактическое поведение:** выводится сообщение "Книга уже есть", добавления не происходит.
- **Причина:** сравнение шло только по автору.
- **Исправление:** добавлено одновременное сравнение по названию и автору.

## Баг 2: удаление не сохраняется
- **Шаги воспроизведения:** удалить книгу через вызов функции `remove_book`, перезапустить программу.
- **Ожидаемое поведение:** при новом старте книга остаётся удалённой.
- **Фактическое поведение:** книга появляется снова.
- **Причина:** сохранение `save_books` не вызывалось автоматически внутри функции `remove_book`.
- **Исправление:** вызов `save_books(books)` добавлен непосредственно внутрь функций `add_book` и `remove_book`.
